# 万卷文渊 · 管理端

把《四库全书》做成可以阅读、可以续编的数字版，让中华文化被更多人读到、用到、传下去。

本仓库是管理端。运营人员在这里登录后台，整理分类、作者、典籍、篇章、封面和 PDF，读者看到的书库由这里维护。读者站和接口在配套仓库 `cloud-mall`。

## 谁可以运营

有能力的组织、公司、个人、团体都可以运营自己的文渊：

- 自建书库，按经、史、子、集和现代学科收录典籍
- 上传封面与 PDF，对读者开放双页阅读
- 用后台账号、角色和菜单管理编目人员

运营方自行整理书目和原文。仓库提供系统和目录脚本，不附带《四库全书》全文。

需要协助做二次开发、把录入、阅读和编目改得更好用，请在本仓库的 Issues 里留言。说明你的机构、想改的部分，以及希望系统变成什么样。作者可以协助改进。

## 这个仓库是什么

基于 JeecgBoot Vue3（3.9.5）的管理后台，本地开发端口 `3100`。

后台里的「万卷文渊」包括：

| 模块 | 作用 |
| --- | --- |
| 典籍作品 | 书名、作者、分类、封面、PDF、文字方向 |
| 篇章正文 | 按卷册维护章节 |
| 分类 / 作者 / 关键词 | 编目 |
| 轮播 / 榜单 / 统计 | 读者站首页 |
| 门户用户 | 读者账号 |
| 书法字帖 / 视频课程 | 与典籍并列的内容入口 |

接口通过 `/jeecgboot` 代理到 `http://localhost:8080/jeecg-boot`。配置在 `.env.development`。

## 本地运行

需要先启动 `cloud-mall` 的 `MallApplication`（端口 `8080`，上下文 `/jeecg-boot`），并在业务库中执行该仓库 `docs/sql` 下的脚本。

```bash
pnpm install
pnpm dev
```

浏览器打开 http://localhost:3100 。

Node.js 18 及以上。包管理用 pnpm。

本地初始管理员为 `admin` / `123456`。对读者或公网开放前，先在后台改掉这个密码。

生产构建：

```bash
pnpm build
```

构建前把 `.env.production` 里的 `VITE_GLOB_DOMAIN_URL` 改成你的后端地址。

## 配套仓库

| 仓库 | 内容 |
| --- | --- |
| `cloud-book-views`（本仓库） | 管理端 |
| `cloud-mall` | 后端接口、读者站、建表与菜单脚本 |

两个仓库一起部署，才是一套可以编目、可以阅读的万卷文渊。
